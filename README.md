# All-in-One Utility Hub 🚀

A production-ready, local "All-in-One Utility Hub" web application built with **Python Flask** and modern **Tailwind CSS**, mimicking a professional platform like iLovePDF combined with HD AI image and developer utilities.

## ✨ Highlights & Features

- **34 Free, Powerful Tools**:
  - **PDF Power Suite**: Merge PDF, Split PDF, Compress PDF, PDF to Word, Word to PDF, PDF to JPG, JPG to PDF, Rotate PDF, Watermark PDF, Protect/Unlock PDF.
  - **AI & Image Studio**: HD AI Background Remover (`rembg`), Image Resizer, Format Converter (PNG/JPG/WEBP/ICO/BMP/TIFF), Image Compressor, Filters & Effects (Grayscale, Sepia, Blur, Sharpen, Invert), Image Cropper, Image to Base64, Image Watermark, EXIF Stripper, Color Palette Extractor.
  - **Document & Data Converters**: Excel to PDF, Excel to CSV, CSV to Excel, JSON to CSV, CSV to JSON, Markdown to HTML, HTML to Markdown, XML to JSON.
  - **Developer Utilities & Security**: QR Code Generator, File Checksum/Hasher (MD5, SHA1, SHA256, SHA512), Base64 Codec, Text Diff Checker, Text Case Converter, URL Encoder/Decoder.
- **100% Private & Local**: Zero files uploaded to the cloud. Process gigabytes of files with zero rate limits.
- **Modern UI/UX**: Fast search, responsive Tailwind CSS grid, drag-and-drop file upload, live progress spinners, interactive image and swatch previews, and one-click downloads.

## 🛠️ Quick Start Guide

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the Application
```bash
python app.py
```

### 3. Open in Browser
Open your browser and navigate to:
```
http://127.0.0.1:5000
```
